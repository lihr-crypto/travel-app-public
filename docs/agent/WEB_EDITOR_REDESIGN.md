# Web 编辑详情改版（2026-10-29）

目标：让一项行程的名称、地点、类型、时间与备注构成一张完整编辑页。沿用现有绿色、系统中文字体、数据与保存语义，只调整本次编辑组件。

## 参考与取舍

- [Tripsy 官方产品界面](https://tripsy.app/)的 Places 图示：地点名称、地址、日期按层级排列，列表连续，用少量图标帮助识别。参考其内容层级，未采用彩色分类图标、玻璃效果或路线功能。
- [Tripsy 活动管理](https://tripsy.help/article/92-managing-your-activities)：低频操作通过活动菜单组织。本页将打开地图、移除地点放入地点行的更多菜单，整行点按可更改地点。
- [Tripsy 日期与时间](https://tripsy.help/article/98-move-activities-in-your-itinerary)：时间直接编辑。保留本产品“无时间/时段/具体时间”三种语义，具体时间采用双列表单，仅已有值显示清除操作。
- [Wanderlog 官方 App Store 截图](https://apps.apple.com/us/app/wanderlog-travel-planner/id1476732439)：内容和分区标题优先，分类入口用一排图标与短文字识别。参考其紧凑分类排布，未新增任何其余功能。

上述是本轮从公开界面归纳的设计取舍。第三方截图只用于本机参考，没有加入产品资产或发布包。

## 布局

日期作为上下文；名称为可直接编辑的主标题，关联地点为其下的一行。六类入口放在一排，选中项使用浅绿反馈。时间方式采用文字选项与下划线，时段为四个等宽选项。备注保留轻底色输入区。单一底色贯穿整个页面，分区通过字重、共同左边缘和 26px 节奏分开。

保留底栏保存、取消、关闭、焦点循环、16px 以上输入、时间草稿、住宿隐藏日期和交通旧起终点。未恢复文件导入/导出，未改数据库、地图逻辑或原生 App。
