# Web 选中态对齐与末尾分割线（2026-10-29）

用户反馈每日行程和底部导航之间出现双线，选择日期时选中行文字右移，并要求检查其他同类页面。

## 修正

- 日期选择与日期策略原先仅在选中后增加 `padding-inline:12px`。现在各状态使用相同内边距，背景向外留出空间，文字继续沿原内容边缘对齐。
- 日期行采用固定日序号列；单、双位日序号的日期列对齐，可选“当前”标记不会挤动日期。
- 旅行范围、首页筛选、类型、时间模式和时段的选中/未选中字重保持一致，反馈采用颜色、底色或下划线；移除编辑控件按下时的 1px 位移。
- 列表只在相邻条目之间保留线，隐藏最后一行的末尾规则；取消每日底部导航上边线。危险操作分组边界只保留单线。
- 同类末尾规则覆盖首页、总览、未安排、日期、搜索结果、版本/恢复记录、旧旅行、回收站及地图行程列表。Native 行程行只把末尾边框变透明，保留原 1px 宽度与拖拽测量尺寸。

仅修改 Web 样式。数据、日期策略命令、登录恢复、地图、排序和原生 App 均未调整。用户随后要求合并部署，发布结果见下。
