# Web 界面风格统一（2026-10-29）

沿用已确认的连续编辑页，统一其他 Web/PWA 页面。范围为现有页面的颜色、字号、留白、列表、表单与弹窗，不新增业务功能，也不恢复单趟文件入口。

## 页面与取舍

| 页面 | 调整 |
| --- | --- |
| 我的旅行 | 标题更明确，筛选为轻量文字标签和绿色下划线；日期与天数/地点/状态分两行，避免窄屏尾字孤立换行；新建保持 44px 触控区域 |
| 旅行总览 | 标题、日期、操作及日列表共用左边缘；淡化 Day 标记，日期与摘要层级清楚 |
| 每日行程、未安排 | 对齐时间与标题列，统一行高、次要文字和操作区；未安排类型与地点页共用编辑器的线条图标 |
| 新建与日期调整 | 轻底色字段，范围选项合并为有标签的控件组；减少外围边框，日期策略保留明确选中反馈 |
| 旅行/日期/行程菜单 | 连续列表、低频危险动作独立分隔，原确认流程保留 |
| 日期选择 | 连续日期行，当前日期使用浅绿反馈 |
| 共享与同步设置 | 统一字段、说明、折叠项和按钮层级，减少卡片轮廓 |
| 地点选择 | 搜索输入、结果图标、地址与地图选择按钮沿用统一样式 |
| 首次使用 | 标题、提示和新建按钮居中成组，宽按钮保留正常圆角 |

主题位于 `web/src/interface-styles.js`。Web 通过现有 testID 限定共用组件的样式；Shared Home 元信息换行和面板底色仅在 `Platform.OS === 'web'` 生效。iOS 原来的视觉值保持，原拖拽、横滑、排序和地图代码未改。

同时发现 RN Web 未将首页的 `accessibilityState.selected` 转成 DOM 选中属性，补充显式 `aria-selected`，并扩展已有回归断言。实际浏览器确认筛选切换后 DOM 状态与下划线同步。
