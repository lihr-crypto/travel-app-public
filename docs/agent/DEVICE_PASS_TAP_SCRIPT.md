# Travel App — 真机验收 · 跟着点就行（2026-10-03 版）

> **怎么用这份清单**
> 1. 按场次顺序做（A → N），每个场次里的步骤按编号来。
> 2. 每一步做完，对照「应该看到」：一致就打 ✓；不一样就打 ✗，再用一句话记下你看到的现象。
> 3. 做完一个场次（或中途遇到怪事）告诉我一声。**需要留证时，把画面停在 App 里，说"截图"**，我立刻抓屏存档。
> 4. 全部做完后我查数据库收尾，你不用管。
>
> 设备：iPhone 17 Pro，App：Travel App（今天构建的版本，已含全部新功能）。

## 开工前（一次性准备，约 2 分钟）

- [ ] 手机连着 Wi-Fi（D/G 场次要搜索地点）。
- [ ] **准备一条住宿数据**（K8/K11 要用）：进入 `2026示例长途旅行` → 任意一天 → `＋ 添加地点` → 随便选个地点 → 类型选 `住宿` → 时间选 `具体时间`：开始 = 今天 19:00，**结束 = 后天 08:30**（点"添加结束时间"后把日期手动改成后天）→ 保存。
- [ ] 记住这条住宿在**哪一天**（开始那天 = 入住日）。

## A 场 — 打开一个行程（约 1 分钟）

用 `2026示例长途旅行` 这个行程（11 天）。

- **A1.** 首页点它卡片上的 `打开旅行`
  ✓ 应该：直接进入行程总览。不白屏、不闪一下地图、不出现"旅行加载中…"。
- **A2.** 把白色抽屉往上拖到一半、再拖到底
  ✓ 应该：抽屉下面始终能看到地图；内容不被屏幕底部的横条挡住；拖到顶时地图还留一条边。
- **A3.** 点抽屉里的 `未安排`
  ✓ 应该：进入一个**独立的"未安排"界面**（不是原地没反应）；里面有内容或显示空状态。按返回回到总览。

## B 场 — 日程页 + 手势（最重要的一场，约 5 分钟）

先随便进入某一天的日程页（比如总览里点 Day 1）。

- **B1.** 从总览点 Day 1 进入日程页
  ✓ 应该：直接显示，不出现"Day 加载中…"；地图和刚才**是同一张**（没有闪黑/闪默认视角）。
- **B2.** 点顶部的右箭头切到 Day 2
  ✓ 应该：画面原地更新——地图不黑屏不白屏，抽屉位置纹丝不动。
- **B3.** 点标题打开日期选择，跳到一个很远的天（如 Day 11），再跳回 Day 2
  ✓ 应该：同样是原地更新，没有整页翻页动画，地图没有变成第二张。
- **B4.** 快速连点两个不同的天
  ✓ 应该：最后停在其中一个，不叠加界面、不残留上一个天的地图标记。
- **B5.** 在**顶部 Day 标题那一整条**（Day N + 日期 + 左右箭头，约 64pt 高）左右滑
  ✓ 应该：滑动能切换上/下一天。★ 只在这一条上滑才有效，在行程列表上滑是滚动，这是设计如此。
- **B6.** 反复点标题选天：开 → 选 Day 2 → 再开 → 选 Day 3 → 再开 → 选 Day 1
  ✓ 应该：每次都能正常打开和选择，没有"点了没反应"。
- **B7.** 点某条行程的 `⋯` → `更换地点`
  ✓ 应该：地点选择器正常出现（不黑屏）；取消返回后日程页完好。
- **B8.** 用手指把地图拖到别处 → 再切到另一天
  ✓ 应该：新的一天显示自己的位置，**不会弹回**你刚才拖走前的画面。
- **B9.** 切换天的时候盯着地图标记
  只需告诉我一句：标记**闪 / 不闪 / 轻微闪**。

## C 场 — 编辑一条行程（约 3 分钟）

- **C1.** 点一条**未选中**行程右侧的 `⋯` → `编辑详情`
  ✓ 应该：直接打开编辑器（没有先弹一个只读详情页）。
- **C2.** 看编辑器内容
  ✓ 应该：有 `地点` 行（可更换/清除）和 `备注`；**没有** `固定行程` 这一项；编辑器里**没有**改日期的入口（改日期在日程页的 `⋯` 菜单里，C 场不用管）。
- **C3.** 看"时间"部分
  ✓ 应该：`无时间 / 时段 / 具体时间` 三选一；选"时段"出现 上午/中午/下午/晚上；选"具体时间"出现时间行，点时间行才弹出滚轮（不是常驻一个大滚轮）。
- **C4.** 点备注输入框，输入几行字
  ✓ 应该：输入框完整露在键盘上方，光标不会被键盘挡住。
- **C5.** 依次点 标题 → （选"其他"类型时的自定义标签框）→ 备注
  ✓ 应该：每个输入框弹出键盘时都能完整入视野，表单不乱跳。
- **C6.** 收起键盘
  ✓ 应该：布局复位，底部没有残留的空白。
- **C7.** （如果列表里有标题很长的行程）看它的 `⋯`
  ✓ 应该：`⋯` 完整可见可点，行不出现横向滚动。
- **C8.** 改个备注点保存
  ✓ 应该：回到日程页，改动立即显示，其他字段没被误改。

## D 场 — 更换地点（约 3 分钟）

在编辑器里：

- **D1.** 点 `地点` 行的 `更换`
  ✓ 应该：编辑器**先关闭**，再出现地点搜索；搜索打开时定位在**这条行程当前的地点**附近（不是地图上次停留的随机位置）。
- **D2.** 搜索并选一个新地点 → 确认
  ✓ 应该：回到日程页，这条行程被选中、地图标记移到新位置；**没有**额外弹出一个编辑表单；标题/时间/备注原样保留。
- **D3.** 再来一次，这次走 `在地图上选择地点`（十字准星）
  ✓ 应该：同样干净返回，标记到准星位置。
- **D4.** 确认新地点后看地图
  ✓ 应该：地图停在**新**地点，不飞回旧位置。
- **D5.** 进编辑器点 `清除` 地点
  ✓ 应该：标记消失，**其余标记的编号没有跳号**（1、2、3 连续）；编辑器还开着，地点行显示未设置。
- **D6.** 搜索时注意候选来源
  ✓ 应该：这个中国行程里只出**高德**的候选。

## E 场 — 拍 4 个没拍过的界面（配合 F 场）

这四步只需要**打开并截图**，不用真的执行（F 场会真的执行一次）：

- **E1.** 日程页某行程 `⋯` → `修改日期` → 进 `修改旅行日期` 界面 → 说"截图"
- **E2.** 打开 `整趟改期` 界面 → 说"截图"
- **E3.** 打开 `删除这一天` 的确认框 → 说"截图"
- **E4.** 做一个会弹 Toast 的操作（比如成功改一次日期）→ 说"截图"

## F 场 — 真实写入（数据库证据，我来查）

  执行完告诉我"F1 完成"，我立刻拉取手机上的数据库和基线做对比——这是"写库真实发生"的证据，你不用做任何事。

## K 场 — 删除行程 / 撤销 + 住宿卡片（新功能）

> 前置：开工前准备的那条住宿数据在行程里。

- **K1.** 进入任意一天，点某条行程的 `⋯`
  ✓ 应该：菜单里有红色的 `删除行程`（和其他操作用线隔开）。
- **K2.** 点 `删除行程`
  ✓ 应该：那行**立即消失**；屏幕底部弹出深色条 `已删除「标题」 撤销`；总览的计数同步变少。
- **K3.** 5 秒内点 `撤销`
  ✓ 应该：深色条消失，行程**回到原来的位置**（前后邻居和删除前一致）。
- **K4.** 再删一条，**等 6 秒不碰它**
  ✓ 应该：深色条自己消失，行程保持已删除（去"未安排"里找不到它——是真删除）。
- **K5.** 删一条行程 → **马上**去日程页 `⋯` → `管理旅行日` 把这一天删掉 → 回原来的天
  ✓ 应该：出现 `无法恢复：该日程已被删除。`，且**没有**可点的 `撤销` 按钮（不是挂着一个点了没用的按钮）。
- **K6.** 回总览
  ✓ 应该：日期块下方出现 `⚠ N 个行程需要确认`；点开展开 ⚠ 列表，每条带 `查看`。
- **K7.** 点某条 ⚠ 的 `查看`
  ✓ 应该：跳到对应的天；如果那条行程在"未安排"里，就跳到未安排界面。
- **K8.** 找到住宿的**入住日**，然后切到**第二天、第三天**
  ✓ 应该：第二天顶部出现 `🏨 今晚住宿 · 酒店名`；**退房那天**顶部出现 `🏨 今早退房 · 酒店名 / 退房 08:30`；**入住当天没有卡片**（酒店本身就在那天的列表里）。
- **K9.** 任意天 → `＋ 添加地点` → 类型选 `交通`
  ✓ 应该：出现 出发地 / 目的地 / 班次 三个输入框 + 方式按钮（航班/火车/巴士/轮渡/用车）；"时间"行变成 出发时间 / 添加到达时间。
- **K10.** 填完保存，再打开编辑器
  ✓ 应该：出发地/目的地/班次/方式**全部回显**，时间行仍是 出发/到达。
- **K11.** （把那条住宿的结束时间临时改成早于入住）回总览看 ⚠ 列表
  ✓ 应该：出现 `退房时间早于入住时间`。测完把时间改回来。

## L 场 — 长按拖拽排序（新功能）

找一个有 **3 条以上行程**的天。

- **L1.** 在行程行上**快速**上下滑
  ✓ 应该：列表正常滚动，顺序不变。（快速滑 = 滚动，这是设计。）
- **L2.** 在一条行程行上**按住约半秒不动**
  ✓ 应该：那行出现高亮（浅绿底 + 描边），期间列表不再跟着手滚动。
- **L3.** 按住不放，往下拖越过下一行的中间位置
  ✓ 应该：列表实时重排（行程跟着手指换位）；松手前数据库没有任何变化。
- **L4.** 松手
  ✓ 应该：顺序**就是**刚才预览的顺序，不回弹、不错位。
- **L5.** 杀掉 App 重开，回到这一天
  ✓ 应该：新顺序还在（不丢、不重复）。
- **L6.** 再长按一条，拖**很小一点距离**（不到半行高）就松手
  ✓ 应该：顺序不变（不抖动）。
- **L7.** 长按一条后**原地不动**直接松手
  ✓ 应该：顺序不变；高亮消失干净；这一行还能正常点选。
- **L8.** 长按一条后**往左右**拖再松手
  ✓ 应该：顺序不变、天不切换；之后在 Day 标题栏左右滑，切天仍正常。
- **L9.** 同一行连续长按拖拽 3 次
  ✓ 应该：每次都生效，第 2、3 次不会"失灵"。

## M 场 — 移出当天 / 从未安排搬回来（约 2 分钟）

- **M1.** 任意天 → 某条行程 `⋯`
  ✓ 应该：菜单里有 `修改日期`（和 `编辑详情`、红色 `删除行程` 分隔）。
- **M2.** 点 `修改日期`
  ✓ 应该：弹出移动面板，里面有各天列表和 `移至未安排`。
- **M3.** 点 `移至未安排`
  ✓ 应该：面板关闭，这条行程从当天消失，页面**停在原天**（不被踢回总览）。
- **M4.** 返回总览 → 点 `未安排`
  ✓ 应该：刚移出的行程就在里面，标题一致。
- **M5.** 在未安排界面点它的 `安排到日期` → 选一个天
  ✓ 应该：行程离开未安排，出现在目标天的列表里，位置合理。
- **M6.** 杀掉 App 重开
  ✓ 应该：行程还在，位置和 M5 一致（不丢数据）。

## N 场 — 首页旅行足迹地图（新功能，重头戏）

- **N1.** 打开 App 停在首页
  ✓ 应该：全屏**苹果地图**（不是高德/Google）；底部是 `我的旅行` 白色面板（半开）；地图上有行程标记。
- **N2.** 看两个标记的位置
  ✓ 应该：两条行程各一个标记，落点正确——中国行程在北京/示例地区一带，日本行程在日本（这是**坐标对齐**检查）。
- **N3.** 点一个标记
  ✓ 应该：**只是选中**并弹出一张小卡（标题 + 日期），不跳转；标记高亮。
- **N4.** 点卡片上的 `查看旅行`
  ✓ 应该：进入该行程的**总览**（不是某一天）。
- **N5.** 返回首页，从 `我的旅行` 面板里点同一行程
  ✓ 应该：行为和 N3/N4 完全一样（列表行和地图标记是一个东西的两面）。
- **N6.** 双指放大到城市级别
  ✓ 应该：原本合并的标记**自动拆开**成多个。
- **N7.** 点筛选 `计划中` / `已完成` / `全部`
  ✓ 应该：地图标记和面板列表同步变化；**没有**"旅行中"这个选项；正在进行中的行程只出现在"全部"里。
- **N8.** 如果有正在进行中的行程（现在有：日本 test）
  ✓ 应该：地图上出现 `● 正在旅行 Day N` 卡片；点开展开，能看到今天的安排和 `继续今天的行程`。
- **N9.** 点 `继续今天的行程`
  ✓ 应该：直接进入行程并**停在今天这一天**（不是总览），无加载白屏。
- **N10.** 点面板标题行的 `＋`
  ✓ 应该：面板内容变成新建行程表单；能关掉回到列表。
- **N11.** 新建一条行程并保存
  ✓ 应该：表单关闭，**新行程立刻出现在地图和列表上**（不用重启）。
- **N12.** 上下拖动 `我的旅行` 面板
  ✓ 应该：三档吸附正常，地图始终可见。
- **N13.** 看面板和地图的关系
  ✓ 应该：面板不会永久挡住地图上的足迹；卡片保持紧凑。
- **N14.** 连续点开/关闭预览卡片 5 次
  ✓ 应该：每次都能正常开关，无残留遮罩、不卡死。

已知小限制（不是缺陷）：地图上聚合气泡显示的是地点名（如 `天安门 · 2 次旅行`）而不是城市名——数据里没有城市字段，已记录为技术债。
